# Case Velsis para Portfólio

## Visão geral
Projeto desenvolvido como um case único para a Velsis, unindo apuração de infrações de velocidade com uma visão mais ampla de monitoramento operacional e arquitetura de software.

## Objetivo
Demonstrar capacidade de transformar um problema de negócio em uma solução técnica organizada, testável e preparada para evolução.

## Cenário prático
Este case simula uma situação real de operação viária, em que é necessário validar eventos de velocidade, identificar infrações, registrar ocorrências e manter um fluxo de acompanhamento confiável para equipes de supervisão e operação.

## Destaques
- API REST estruturada
- Regras de negócio claras
- Tratamento de erros consistente
- Testes e documentação
- Arquitetura preparada para evolução
- Visão de solução voltada para contexto operacional real

## Mensagem de posicionamento
Este repositório representa mais do que um desafio técnico: é uma proposta profissional de solução, com narrativa coesa, contexto operacional real e valor percebido para avaliação, entrevista e portfólio.

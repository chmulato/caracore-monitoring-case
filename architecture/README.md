# Arquitetura do Case

Esta pasta centraliza a visão arquitetural do projeto, mantendo um discurso único sobre a solução consolidada da Velsis.

## Objetivo
Apresentar a solução como uma proposta coerente de serviço viário, unindo:
- regras de negócio e apuração;
- monitoramento operacional;
- estrutura de software preparada para evolução.

## Perspectiva do projeto
A arquitetura é entendida como uma base para um serviço viário mais completo, com foco em clareza, escalabilidade e qualidade de entrega.

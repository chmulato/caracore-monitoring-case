# Arquitetura do Case

Esta pasta centraliza a visão arquitetural do projeto, mantendo um discurso único sobre a solução.

## Objetivo
Apresentar a solução como uma evolução coerente do desafio, unindo:
- regras de negócio e apuração;
- monitoramento operacional;
- estrutura de software preparada para evolução.

## Perspectiva do projeto
A arquitetura é entendida como uma base para um serviço viário mais completo, em vez de um exercício isolado.

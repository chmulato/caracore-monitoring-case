# Visão de Arquitetura

A solução foi concebida como uma plataforma de apoio à operação viária, estruturada de forma modular e preparada para evolução.

## Camadas principais
- Interface: endpoints REST para avaliação e consulta.
- Aplicação: regras de negócio, validações e orquestração.
- Domínio: lógica relacionada à apuração e classificação de ocorrências.
- Persistência: armazenamento em memória para o cenário proposto.

## Perspectiva de evolução
A arquitetura permite que o projeto evolua para cenários mais completos de monitoramento, observabilidade e integração com componentes operacionais.

## Mensagem de arquitetura
A proposta não é apenas resolver um teste técnico, mas demonstrar uma visão de solução alinhada a um cenário real de negócio.

# Roteiro de Apresentação

## 1. Abertura
Apresentar o projeto como um case único de solução para a Velsis, com foco em operação viária, regras de negócio e arquitetura.

## 2. Contexto do problema
Explicar que o desafio envolve não apenas a validação de uma infração, mas a necessidade de construir uma solução organizada e escalável.

## 3. Solução proposta
Descrever a API, a lógica de negócio, o tratamento de erros e a organização do projeto.

## 4. Extensão do case
Mostrar que o projeto também incorpora uma visão de monitoramento operacional e evolução arquitetural, alinhada ao desafio HD.

## 5. Evidências técnicas
Destacar:
- estrutura em camadas;
- testes;
- documentação;
- clareza de fluxo.

## 6. Fechamento
Concluir que o projeto representa uma proposta profissional, com narrativa coesa e valor percebido para avaliação, entrevista ou apresentação de portfólio.
